# ⚡ CONFIGURACIÓN RÁPIDA: MCP SERVER SUPERIOR

## 🚀 **CONFIGURACIÓN PRIORITARIA (GRATIS)**

### **Paso 1: Configurar MiniMax M2 GRATUITO**

**Lo más importante es configurar estas 2 variables para tener IA gratis:**

```bash
# Obtén tu API key gratuita de OpenRouter
OPENROUTER_API_KEY="sk-or-v1-[tu_key_aquí]"
MINIMAX_MODEL_NAME="minimax/minimax-m2:free"
```

**Cómo obtener OpenRouter API Key:**
1. Ve a [OpenRouter.ai](https://openrouter.ai)
2. Sign up (gratis)
3. Generate API Key
4. ¡Listo! Tienes acceso gratuito a MiniMax M2

### **Paso 2: Variables Mínimas (Todo Gratis)**

```bash
# Copia el template
cp .env.template .env

# Edita solo estas líneas prioritarias:
OPENROUTER_API_KEY="sk-or-v1-[tu_key]"
MINIMAX_MODEL_NAME="minimax/minimax-m2:free"

# Opcional: Google Maps para ubicaciones (10K gratis/mes)
GOOGLE_MAPS_API_KEY="[tu_maps_key]"
```

### **Paso 3: Ejecutar**

```bash
# Instalar dependencias
pip install -r requirements.txt

# Ejecutar sistema
python main.py
```

**¡Y ya está! Tienes el ecosistema completo funcionando con IA gratuita.**
