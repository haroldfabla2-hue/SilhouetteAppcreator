# Investigación Completa: Plataforma MiniMax Agent y Asistente Iris

**Fecha de Investigación:** 5 de noviembre de 2025  
**Autor:** MiniMax Agent

---

## Resumen Ejecutivo

MiniMax Agent es una plataforma avanzada de inteligencia artificial que permite a los usuarios crear, personalizar y ejecutar agentes de IA especializados para una amplia variedad de tareas. La plataforma combina capacidades multimodales, sistemas multiagente, y una arquitectura flexible que facilita la automatización de procesos complejos.

---

## 1. Interfaz de Usuario

### 1.1 Diseño y Layout Principal

**Interfaz Principal del Asistente Iris:**
- **Diseño de dos paneles:**
  - Panel izquierdo: Área de contexto y entrada de información
  - Panel derecho: "MiniMax's Window" con pestañas de proceso y archivos
- **Esquema de colores:** Tema oscuro profesional con acentos en púrpura/rosa
- **Navegación:** Intuitiva con botones claramente etiquetados
- **Responsividad:** Adaptable a diferentes tamaños de pantalla

**Elementos de Navegación Identificados:**
- Logo MiniMax (enlace a página principal)
- Botón "New Task" para nuevas tareas
- Galería de agentes pre-construidos
- Historial de tareas
- Sección "About MiniMax"
- Opciones de descarga y documentación

### 1.2 Componentes de Interfaz

**Panel de Entrada (Izquierda):**
- Área de texto grande para prompts y contexto
- Botones de ejecución: "Lightning" (rápido), "Pro" (profesional), "Run"
- Categorías de tareas: Recommend, Code, Research, PPT, Multimodal, Others
- Indicadores de estado del proceso ("Replaying task...", "Completed")

**MiniMax's Window (Derecha):**
- Pestaña "Current Process": Muestra el estado en tiempo real
- Pestaña "Files": Gestión de archivos generados
- Botón de cierre
- Funcionalidad de scroll para contenido largo
